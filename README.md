# ChinaPriceAR

Android-приложение (Kotlin, Compose, CameraX, ML Kit): наводите камеру на китайский ценник —
поверх изображения появляется русский перевод названия и цена в рублях.

## Сборка без Android Studio
1. Создайте пустой репозиторий на GitHub и загрузите в него содержимое этого архива (в корень).
2. Ветка `main` → вкладка **Actions** → **Build Debug APK** (запустится сам при push или через *Run workflow*).
3. По завершении скачайте артефакт **app-debug** — внутри `app-debug.apk`.

Gradle Wrapper (`gradlew`, `gradlew.bat`, `gradle-wrapper.jar`) генерируется на CI шагом `gradle wrapper`.

## Первый запуск
Нужен интернет: скачивается модель перевода (zh→ru через en) и курс. Дальше перевод работает офлайн,
курс берётся из кэша.
